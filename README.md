# Wei Jun Tan's portfolio

This site is built with React and Vite and deployed to GitHub Pages.

## Available scripts

### `npm start`

Runs the Vite development server.

### `npm run build`

Builds an optimized production bundle in the `build` directory.

### `npm run preview`

Serves the production build locally for verification.

### `npm run deploy`

Builds the site and publishes the `build` directory to the `gh-pages` branch.

### `npm run audit`

Checks the installed dependency tree against npm's security advisory database.
